☁️ Sincronizar en tiempo real

Conecta la app a Firebase (gratis) para que tus datos estén en la nube: así, si abres la app en Chrome, Brave, otro celular o tu pareja vende contigo, todos ven los mismos datos en tiempo real. Solo pega la misma configuración en cada navegador.

Estado: No conectado
Configuración de Firebase
Cómo obtener la configuración (1 sola vez)
1. Entra a https://console.firebase.google.com e inicia sesión con Google.
2. Toca Crear proyecto → ponle un nombre (ej: mis-huevos) → Continuar → Crear.
3. En la página del proyecto toca el ícono </> (Web) → escribe un apodo → Registrar app.
4. Te muestra un código. Copia solo la parte const firebaseConfig = { ... }; (el bloque con llaves).
5. En el menú izquierdo: Compilación → Realtime Database → Crear base de datos → elige ubicación → en modo de reglas elige Modo de prueba → Habilitar.
6. Vuelve aquí, pega el bloque en el cuadro y toca Guardar y conectar.
7. En cada navegador que uses (Chrome, Brave, celular) abre la app y pega la misma configuración. Listo: los datos se sincronizan solos.
